## Request Types

### GET
To be used for retrieving data.
Accepts any field as a search filter function when sent as a QUERY. 
Will return unlimited number of results (may be paginated in future)

### POST
To be used for adding a new line.
Accepts all fields except uuid. 
Only the server can assign uuids. 
Response will include added entry.

### PUT
To be used for editing preexisting data.
The uuid MUST be included to select which row is to be edited.
Response will include updated entry.

### DELETE
To be used for deleting data.
The uuid MUST be included to select which row is to be deleted.
Will run even if the uuid is not found in the database.
Will include deleted uuid in response.
